## Exercise 2 — Identify a Linux distribution

**Environment:** Authorized HTB Academy Pwnbox.

```bash
cat /etc/issue
```

**Observed output:** Parrot Security 7.1 (with login-banner escape sequences).

**Submitted answer:** `Parrot`.

**Troubleshooting:** The first attempt omitted the space after cat. The second used an incorrect relative filename. The correct command separates the executable and absolute file path with a space.

**Learning outcome:** Read a Linux file and identify the operating system.
