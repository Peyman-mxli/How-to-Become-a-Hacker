**Status:** Completed on November 23, 2026

**Achievement:** Academician badge

## Study notes

1. **Introduction:** Guided learning combines theory, practical exercises and assessments.
2. **Academy structure:** A path contains modules; modules contain sections. Work through manageable lessons before attempting certification exams.
3. **Modules:** Categories include Offensive, Defensive, Purple and General. Difficulty is separate from cost. Tier 0 costs and rewards zero Cubes; the supplied lesson describes paid tiers returning 20% on completion.
4. **Sections:** Theory builds foundations; interactive lessons test understanding. Pwnbox is a browser-based Parrot Linux workstation. Keep technical notes and use cheatsheets for revision.
5. **Exercises:** Authorized Docker targets can expose a web service through an IP address and port; VM targets may require Academy VPN connectivity from a local computer. Pwnbox can access Academy lab environments.
6. **Paths and certifications:** Skill paths focus on particular capabilities; job-role paths prepare learners for a profession and associated practical exam. Enrollment does not automatically unlock modules.
7. **Getting help:** Use Academy support, hints and community resources. Subscription-only guided solutions are optional.
8. **Next steps:** Start with fundamentals and progress toward a cybersecurity role. The Junior Cybersecurity Analyst path is the suggested beginner route.
