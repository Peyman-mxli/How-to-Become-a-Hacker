# Lesson 02 — Linux Distributions

## Overview
A distribution combines the Linux kernel with software packages, configuration, package management and user interfaces. Distributions target different workloads, including desktops, servers, cloud infrastructure, embedded systems and authorized security testing.

## Examples

| Distribution | Common use |
| --- | --- |
| Ubuntu | Desktop, servers and general-purpose computing |
| Debian | Stable general-purpose and server environments |
| Fedora | Desktop and software development |
| CentOS | Enterprise-oriented Linux environments |
| Red Hat Enterprise Linux | Enterprise computing |
| Kali Linux | Security assessment and penetration testing |
| Parrot OS | Security, privacy and development |
| Raspberry Pi OS | Raspberry Pi devices |
| BackBox | Security assessment |
| BlackArch | Security testing |
| Pentoo | Security assessment |

Distributions differ in bundled tools, software repositories, configuration and user interfaces. No distribution is automatically secure; configuration, maintenance and updates matter.

## Debian
Debian emphasizes stability, reliability and flexibility. It is used on desktops, servers and embedded systems. Its APT (Advanced Package Tool) package management system supports software installation and updates, including security patches. Automatic updates require appropriate configuration. Debian long-term support can extend coverage to five years for supported releases and packages.

Ubuntu, Kali Linux and Parrot OS are Debian-based distributions. HTB Academy Pwnbox uses a customized Parrot OS environment.

## Security relevance
Open-source software and configurable environments allow security practitioners to inspect systems, select appropriate tools and tailor their workflows to authorized tasks. Learning fundamental Linux commands is more transferable than relying exclusively on a particular distribution.
