# Lesson 03/30 — Introduction to Shell

## Overview
Linux shell proficiency is important for server administration and authorized cybersecurity work. A shell interprets text commands and provides access to programs, files and system functions.

## Terminology
| Term | Meaning |
| --- | --- |
| Terminal | Interface for text input and output |
| Shell | Command interpreter |
| CLI | Command-line interface |
| GUI | Graphical user interface |
| Kernel | Core operating system component managing system resources |
| Console | System text interface |
| Terminal emulator | Software providing terminal functionality, often inside a GUI |
| Terminal multiplexer | Tool managing multiple terminal sessions and panes |

A terminal and a shell are related but distinct: the terminal presents the interface and the shell interprets commands. Tmux is a terminal multiplexer that supports multiple sessions, windows and panes.

## Shells
Bash (Bourne-Again Shell), part of the GNU project, is widely used. Other shells include Zsh, Fish, Ksh, Csh and Tcsh. Shell scripting enables automation and reduces repetitive manual work.
