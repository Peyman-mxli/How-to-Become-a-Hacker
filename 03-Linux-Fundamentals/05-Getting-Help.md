# Lesson 05/30 — Getting Help

## Overview
Linux provides documentation and command-specific help. Rather than memorizing every option, learn to locate and interpret manuals and usage information.

## Commands from the lesson

| Command | Purpose |
| --- | --- |
| `ls` | List directory contents |
| `man ls` | Open the detailed manual for ls |
| `ls --help` | Display a quick reference for ls options |
| `curl -h` | Display curl's short help |
| `apropos sudo` | Search manual page names and descriptions for sudo |

Use q to leave the manual viewer, arrow keys to navigate, and h for pager help. Help switches vary by program; do not assume that -h always means help.

## Useful ls options

| Option | Meaning |
| --- | --- |
| -a | Include hidden entries |
| -A | Include hidden entries except . and .. |
| -l | Long listing format |
| -la | Combine long format and hidden entries |

The last example is supplemental practice. Hidden files generally begin with a dot.

## Learning outcome
Use manuals to discover syntax, arguments and options; use keyword searches when the relevant tool is unknown. Consult documentation before running unfamiliar commands.
