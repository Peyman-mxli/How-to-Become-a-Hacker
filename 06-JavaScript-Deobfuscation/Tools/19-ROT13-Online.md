# ROT13 Online — Browser Reference

ROT13 is a reversible alphabet substitution using a fixed 13-position shift. The browser tool is a convenience for non-sensitive data.

## Official access
- https://rot13.com/
- Local alternative: [GNU tr](18-tr-ROT13.md)

The site was reachable and requires JavaScript; interactive conversion was not independently tested. No official standalone installer or open-source distribution was verified. Use GNU tr offline for private data.

## Usage and example
Open the site, enter non-sensitive text such as Hello World, select ROT13 if the UI offers multiple transformations, and inspect the result. Expected: Uryyb Jbeyq. Applying ROT13 again yields Hello World. Exact interface may vary; no live conversion was performed.

## Troubleshooting and security
If the interface is blank, check JavaScript availability or use local tr rather than disabling browser security. If output differs, check the selected transformation and ASCII input. Do not submit private project code, credentials, student data or assessment values. ROT13 is not secure encryption.
