# dCode Cipher Identifier — Encoding Recognition

A cipher identifier proposes possible encoding/cipher types from observed text. dCode describes statistical and pattern-based techniques and machine learning. Results are hypotheses, especially with short or layered inputs.

## Official access and download
- https://www.dcode.fr/cipher-identifier
- https://www.dcode.fr/

The official tool is free to access online. The provider states that its source code and offline distribution are not public; no official offline installer is available from that page. This is a free-to-use service, not verified open source. Prefer the open-source CyberChef alternative for local use.

## Original example and usage
Open the official page; paste a harmless value, such as SGVsbG8gV29ybGQ=, in Ciphertext to recognize. Optional clues may be supplied. Select Analyze, examine candidates, then verify the suspected method with a trusted decoder. The known example is Base64 for Hello World, but no actual dCode ranking was captured. The similarly harmless hex string 48656c6c6f20576f726c64 decodes to the same text.

## Troubleshooting and security
Short strings can be ambiguous; pure hex can also match other alphabets. Preserve original data, decode as data, and corroborate with context and re-encoding. Modern ciphertext may resist automatic identification. Never execute recovered code or send private values to a third-party service. No tool execution or additional HTB credit claimed.
