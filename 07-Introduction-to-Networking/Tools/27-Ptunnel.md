# ptunnel / ptunnel-ng — ICMP tunnel concepts

Ptunnel-family tools encapsulate TCP communication within ICMP echo traffic. ICMP is normally used for network diagnostics and control, not application-level proxy inspection. Encapsulation is not inherently encryption. Unauthorized tunneling may reduce visibility at controls that inspect only conventional application flows. [ptunnel-ng official source](https://github.com/utoni/ptunnel-ng), [original Windows port source](https://github.com/ptunnel-win/ptunnel).

Installation reference: use official repository and documented platform dependencies in an isolated authorized lab only if required later. Do not install or run a tunnel today. For a previously installed ptunnel-ng binary, consult its official help/man documentation for version and configuration; no live listener or packet transmission is needed. Defensive example: investigate persistent high-volume or unusual ICMP echo patterns by correlating host process, destination, baseline and approved monitoring tools. ICMP is needed for legitimate network functions; avoid blanket blocking without evaluating operational impact. Apply appropriate egress policies, segmentation and endpoint monitoring. Never use tunnels to evade an organization's firewall or access unapproved systems. UniTrack/ProTrack-MX do not require ICMP tunneling. No installation or execution.
