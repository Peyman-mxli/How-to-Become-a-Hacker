I am an IT & Digital Innovation Engineering student at Universidad Politécnica de Baja California (UPBC), Mexico. I started this documented learning journey on November 23, 2026, with Hack The Box Academy.

This repository is a growing portfolio of original study notes, authorized lab exercises, review questions, command references and learning milestones. My objective is to develop practical skills, understand how systems work, and apply security knowledge responsibly to software development and authorized vulnerability research.

## Learning approach

1. Understand the concept before memorizing commands.
2. Practice in authorized environments.
3. Record errors, observations and reproducible steps.
4. Review what is known and unknown, and ask precise questions.
5. Apply defensive lessons to software projects and improve continuously.

## Ethics and responsible disclosure

All practical security testing must be performed on owned systems or explicitly authorized targets, within the applicable scope. This repository is for education and defensive improvement. Do not use its contents for unauthorized access.

Notes are independently written summaries, not copies of official course material. Only permitted training solutions are included. Private credentials, VPN profiles, session identifiers, restricted assessment answers and sensitive target data must not be committed.
